# 0.1.1-alpha Farming Station update

- Restores dedicated hoe and axe tool slots.
- Restores four planting-supply slots and dedicated harvest-output slots.
- Adds an Ender IO capacitor slot with legacy-style working ranges: 7x7 basic, 11x11 double-layer, 15x15 octadic.
- Restores automatic tilling of dirt/grass into farmland and hoe durability use.
- Adds vanilla sapling planting and powered tree chopping with axe durability use.
- Adds melon, pumpkin, sugar cane, and cactus harvesting.
- Uses legacy-style action costs: 500 FE for normal farming actions and 1000 FE per wood block chopped.
- Keeps Ender IO 6.2.15-beta as a mandatory runtime dependency without compiling against internal Ender IO classes.

Still planned: a proper Farming Station GUI, configurable/locked supply slots, broader modded-crop handlers, and more exact fake-player/tool enchantment parity.
